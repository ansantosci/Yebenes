# Los Yébenes San Bruno · Prototipo web app V10

Versión de prueba para GitHub Pages.

## Cambios V10
- Cada relación entrenador–equipo tiene función, fecha de inicio y fecha de fin.
- Estados automáticos de asignación: Próxima, Activa y Finalizada.
- El acceso del usuario Entrenador a jugadores se limita a los equipos cuya asignación está activa en la fecha actual.
- El administrador informa estas asignaciones al crear un usuario Entrenador.
- Las asignaciones se pueden editar posteriormente desde el inventario de entrenadores, manteniendo periodos históricos.
- Los filtros de entrenadores por categoría, equipo y rol se aplican sobre las asignaciones.

> Prototipo con localStorage. No introducir datos reales ni sensibles.
